# Панель харнессов

## Цель

Локальная веб-панель для поиска сессий, их проектов, файлов и подтверждённых связей, включая Hermes на VPS. По выбору сессии показывает доступную историю диалога, вызовы инструментов и безопасные вложения. Исходные хранилища не изменяются; SQLite читается из временных снимков на машине источника.

## Критерии

- Список источников и сессий: поиск и фильтры по харнессу и проекту; видны реальные пути, отсутствие и ошибки источников.
- Детали: постраничная доступная история, вызовы инструментов, изображения, подтверждённые родительские и дочерние связи и отдельно другие сессии того же проекта; неполные или неподдерживаемые данные обозначены явно.
- В известных корнях харнессов доступны имена, пути, размеры и даты файлов для инвентаризации. Просмотр содержимого ограничен разрешёнными каталогами сессий и артефактов и безопасными типами; конфигурационные файлы и файлы с именами, указывающими на секреты, не открываются. Текст самих сессий может содержать секреты и не редактируется автоматически.
- Открытие расположения выбранной сессии в Finder; исходные данные не изменяются.
- Локальный доступ без телеметрии и сторонних облачных сервисов; удалённый Hermes читается по SSH только с указанного VPS. Произвольное чтение файлов через API и исполнение HTML из источников запрещены.
- Проверка: запуск реального сервера, исследование реальных источников и пользовательских сценариев в браузере; отдельная проверка границ доступа.

## Ограничения и решения

Python стандартной библиотеки и локальные HTML, CSS и JavaScript. DSH использует установленный `zstd`. Сервер слушает loopback. Форматы харнессов могут меняться; при несовместимости необходима явная ошибка, а не выдуманные данные. Актуальный статус не выводится из времени записи файла. Удаление, перенос, редактирование сессий, настройка харнессов и публикация не входят в задачу. Зона повышенного риска: доступ к приватным локальным сессиям и недоверенным путям.

SQLite: пользователь выбрал временные снимки как компромисс для чтения живого WAL без изменения исходной базы. Создаётся закрытая копия базы и WAL на соответствующей машине, включая VPS. При штатном завершении чтения она удаляется; при аварийном завершении процесса может остаться на диске и содержать частные данные. База с rollback-журналом, в том числе неактивным PERSIST, либо изменяющаяся при копировании, отображается недоступной вместо попытки восстановления. Снимок ограничен размером 2 GiB.
