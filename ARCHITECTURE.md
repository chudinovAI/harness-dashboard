# Архитектура

До текущей доработки были одностраничный локальный список, ограниченный просмотр истории и локальные адаптеры; добавлены просмотр источников, страницы истории и удалённый Hermes. Исходное исследование содержит частные сведения и не включается в публичный набор.

| Компонент | Ответственность |
|---|---|
| `server.py` | Loopback HTTP, Host/Origin/токен, снимок индекса, выдача страниц и локальное открытие Finder через macOS file-reference URL. |
| `source_files.py` | Постраничный просмотр разрешённых локальных корней и безопасных текстов/изображений, отказ для секретов и симлинков. |
| `file_adapters.py`, `file_history.py` | Метаданные и страницы OMP, Claude JSONL и DSH zstd, проверка пути и идентичности файла. |
| `db_adapters.py`, `db_details.py` | ZCode, Codex, OpenCode и локальный Hermes; временный SQLite/WAL-снимок и страницы истории. |
| `remote_adapter.py`, `remote_worker.py` | Явно настраиваемый SSH-адаптер Hermes VPS с фиксированным worker, закрытый временный SQLite/WAL-снимок на сервере и страницы истории и разрешённых файлов. Без настройки соединение не выполняется. |
| `index.html`, `app.js`, `styles.css` | Навигация по проектам, сессиям и хранилищам, безопасный Markdown и доступные изображения; содержимое не исполняется как HTML. |
| `tests/` | Поведенческие регрессии чтения, пагинации и границ доступа. |

Данные передаются через внутреннее представление сессии; постоянной собственной базы нет. Страницы истории читаются по идентификатору из последнего индекса; файловые пути ограничены зарегистрированными корнями и открываются без перехода по симлинкам. Временные SQLite-снимки и их ограничения описаны в `README.md`. Сравнение с прежней картой и независимое ревью выполняются при изменении обязанностей или доверительных границ.

Проект в навигации определяется парой «место хранения и путь»: совпадающие пути локальной машины и VPS не объединяются. Связи сессий строятся по этому ключу и доступным родительским идентификаторам; это не доказательство содержательной связи проектов.
