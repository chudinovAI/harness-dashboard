# План

1. Чтение файловых и SQLite-источников, безопасная локальная выдача — `file_adapters.py`, `db_adapters.py`, `server.py`; проверить на реальных источниках.
2. Интерфейс поиска и просмотра — `index.html`, `styles.css`, `app.js`; проверить в браузере, включая ошибки и узкий экран.
3. Независимое ревью реализации и структуры: сравнить с исходным состоянием (до задачи приложения не было), проверить границы данных, контракты и ненужную сложность; отразить существенные выводы в `ARCHITECTURE.md`.
4. Инструкции запуска и фактически проверенные ограничения — `README.md`; окончательная пользовательская приёмка — после обсуждения.

## Выполнено

- Локальные источники OMP, DSH, ZCode CLI, Codex и OpenCode проверены на реальных данных. Локальный Hermes пуст, стандартный каталог Claude не найден; учитывается также `CLAUDE_CONFIG_DIR`.
- Hermes на VPS подключён по существующему SSH-профилю. Проверены список, фильтр сессий с записями и просмотр реальной истории.
- В браузере проверены навигация по папкам, предпросмотр, последующие страницы истории и изображения из тестовой сессии, в том числе из второй страницы. Одинаковые пути локального и удалённого проектов проверены раздельно.
- `python3 -B -m unittest discover -s tests -v`: 16 тестов прошли на системном и Homebrew Python. Независимое ревью реализации и границ доступа: выявленные ошибки исправлены, подтверждённых блокирующих замечаний в итоговых проверках не осталось.
- Hallmark: статическая и визуальная проверки выполнены; исключение для высоты строк сессий документировано, поскольку строки содержат название и метаданные.
- Для чтения SQLite используются временные локальные и удалённые снимки с раскрытым риском остатка после аварии. Гонки живого WAL/checkpoint и некоторые варианты исходных форматов не исчерпывающе проверены. Окончательная пользовательская приёмка интерфейса ожидается.
